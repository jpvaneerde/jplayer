Rooms

When several rooms hear the same song, it counts for the room with the highest priority. A record or CD only counts in a room where a turntable or CD player stands (and only when JPlay Records is connected, below). Rooms appear here when a display reports from them.

JPlay Records (optional)

Connect your JPlay Records to see which of your records or CDs was played (otherwise the hub still keeps every play, but a record is just "heard" and a CD is "a CD"). Create a listener for the hub in JPlay Records → Settings → Listeners and paste its token.

Done by itself every few hours; use this after adding records.

Import
